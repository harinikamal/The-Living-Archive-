# The Living Archive 

A digital literary archive where poems, essays, letters, and stories connect through shared emotions, memories, and experiences.

The Living Archive is built around the idea that writing is interconnected. Explore pieces through themes like longing, grief, belonging, solitude, and home, and discover how different stories echo the same feelings.

## Features

- **Interactive Constellation** — Explore connections between themes and literary pieces.
- **The Archive** — Search, filter, and discover writing by type or theme.
- **Reading Room** — Read poems, essays, letters, and stories in a quiet, paper-inspired space.
- **Submit a Piece** — Contribute writing anonymously or under a pseudonym.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- SVG for the interactive constellation

## Getting Started

Clone the repository:

```bash
git clone https://github.com/harinikamal/The-Living-Archive-.git
cd The-Living-Archive-
```

Run a local server from the project directory:

```bash
python -m http.server 3000
```

Then open `http://loc`
